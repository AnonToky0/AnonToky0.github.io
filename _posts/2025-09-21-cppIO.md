- EOF (End Of File)

## 常见问题

### 1. 输入缓冲区
#### 问题描述

``` cpp
int T;
cin >> T;
string line;
getline(cin, line);
```
#### 问题原因
- cin >> T; 读取整数后，输入缓冲区中还残留了一个换行符 \n，
- 而 getline(cin, line); 会读取这一行直到换行符结束，
- 所以它立即读取了这个残留的换行符，导致 line 变成空字符串。
#### 解决方案
1. 在调用`getline`之前，清除缓冲区中的换行符
``` cpp
cin>>T;
cin.ignore(); // 忽略缓冲区中第一个字符，通常是换行符
getline(cin, line);

```
2. 使用读取代替清除

``` cpp
cin>>T;
cin.get(); // 读取并丢弃一个字符（换行符）
getline(cin, line);

```

3. 先用getline读整行，再用stringstream解析

``` cpp
string firstLine;
getline(cin, firstLine);
stringstream ss(firstLine);
int T;
ss >> T;

getline(cin, line);
```

### 2. 显式输入EOF
#### 问题描述

``` cpp
int T;
while(cin>>T){}
```
在本地调试时会持续等待输入，不能进入代码调试

#### 解决方案
- 显式输入EOF(Linux/Mac下是`Ctrl+D`, Windows下是`Ctrl+z+回车`)  
**注意**：是`Ctrl+z+回车`三个键一起按, 同时Windows和Linux的信号不一样，Ctrl+z在Linux下代表挂起进程，注意是挂起不是终止，终止是Ctrl+c

- 使用文件输入(请参见下面内容)

## 2. 字符串输入处理为二维数组
- 输入： `string input = "[[1,2,3],[4,5,6],[7,8,9]]"`
- 输出： `vector<vector<int>> matrix`

``` cpp
vector<vector<int>> parse(const string &input)
{
    vector<vector<int>> res;
    string trimmed = input;

    // 去掉外层中括号
    if (!trimmed.empty() && trimmed.front() == '[' && trimmed.back() == ']')
    {
        trimmed = trimmed.substr(1, trimmed.size() - 2);
    }

    stringstream ss(trimmed);
    string segment;

    while (getline(ss, segment, ']'))
    {
        if (segment.empty())
        {
            continue;
        }
        // segment 形如 "[1,2,3," 或者 ",[4,5,6," ，先去除多余的 '[' 和 ','
        size_t leftPos = segment.find('[');
        if (leftPos != string::npos)
        {
            segment = segment.substr(leftPos + 1);
        }
        if (!segment.empty() && segment.back() == ',')
        {
            segment.pop_back();
        }
        // 解析数字
        stringstream numss(segment);
        string numberstr;
        vector<int> row;
        while (getline(numss, numberstr, ','))
        {
            if (!numberstr.empty())
            {
                row.push_back(stoi(numberstr));
            }
        }
        if (!row.empty())
        {
            res.push_back(row);
        }
    }
    return res;
}
```

## 3. C语言处理
- 输入：持续输入两个为一组的数据,数据类型不同

``` cpp
#include <stdio.h>
#include <math.h>

int n;
double x;

while(~scanf(%lf%d, &x,&n)){
    //
}
```

**注意**: `~`是按位取反，只有当`scanf`返回`EOF`(-1)时为0;
> 计算机中，带符号整数用补码表示：负数的补码是对其绝对值的二进制取反后加1，所以-1的补码是全1。

## 4. 文件输入

``` cpp
./program < input.txt
```

该操作是重定向，源代码无序做任何操作，相当于将终端输入内容重定向到input.txt
**注意**：PowerShell可能不支持 重定向`<`，但CMD支持。

## 5. 邻接表(Adjacency List)
建立有向图的常用方法

``` cpp
int main(){
    int n,m;
    cin>>n>>m;

    // 创建邻接表，n个顶点，编号假设从1到n
    vector<vector<int>> graph(n + 1);

    for(int i=0;i<m;++i){
        int u,v;
        cin>>u>>v;
        graph[u].push_back(v); // 有向边 u -> v
    }
}
```

## 6. 域宽 (Field Width)
域宽指输出时为某个数据预留的最小字符宽度。即输出字符时至少占某个字符宽度，不足的部分默认用空格填充，默认右对齐。

### 使用方法
`setw`函数原型

``` cpp
std::ostream& setw(int n);
```

`setw`在`<iomanip>`头文件中定义，只对紧跟着的输出有效。

### 使用示例

``` cpp
for (int j = 0; j < (int)nums[i].size(); ++j)
{
    cout << setw(5) << nums[i][j];
}
```

### 注意事项
- 如果想让数字左对齐，可以用`cout << left << setw(5) << nums[i][j];`
- 可以使用自定义字符填充，如`cout << setfill('.') << setw(5) << nums[i][j];`, 会用`.`填充空格
